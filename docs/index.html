A lead that splits the work

Give the lead agent a goal. It writes tasks on a shared board, then starts a worker for each one, every worker in its own git worktree so they never step on each other.

  • To do, In progress, Review and Done, with drag and drop
  • Agents post comments and move their own cards

Review every diff before it lands

Each worktree is diffed against where it branched, side by side. Then commit, merge into your branch, or throw it away.

  • Merging always asks first and stops cleanly on conflicts
  • Fix a line yourself with the built-in editor
  • Worktrees an agent made itself show up too, with who made them

See who's doing what, live

The Graph shows every agent as a node, the lead in the middle. Lines show who messaged whom and how often; dashed lines show who started whom. New messages glow along them.

How it works

Three steps from goal to merged.

  1. Open a project

    Point Agent Desk at any git repo. Start agents by hand, or click Lead agent.

  2. Give the lead a goal

    "Add a wishlist." It plans tasks on the board and starts a worker in a fresh worktree for each one.

  3. Review and merge

    Workers move their cards to Review. Read the diffs side by side, then merge what's good and discard the rest.

Local-first, careful by default

Your code stays on your Mac.

Agent Desk is a local app. Beyond the agents you start, it only reaches out to GitHub: to check for a new release, and to publish a page when you ask.

  • Listens only on 127.0.0.1. Every request needs this install's secret and must come from Agent Desk's own page.
  • A token per agent. Each agent only reaches its own board tools and always acts as itself. The master secret never goes in its config.
  • Ask-me permissions. Claude agents start in "Ask me" mode, and nothing offers the bypass modes.
  • You stay in charge. A lead can't type into or stop other agents without your OK, and merging always asks.
  • Hardened app. Electron's run-as-Node and inspector switches are off, and the hardened runtime is on.

One honest caveat: an agent with shell access runs as you, so it could read files you can. Real isolation would need a separate macOS user.

FAQ

Questions, answered.

What do I need to run it?

A Mac with Apple silicon and Claude Code installed and signed in. Codex, Gemini CLI and Cursor Agent are optional: install any of them and they show up in the New menu.

Does it need an API key, or cost anything extra?

No. Agents run in real terminals with your own CLI logins, so Claude Code uses your normal subscription. The Spend view shows what the same work would cost at API prices, so you know where it went.

macOS says it can't check the app. Is that expected?

Yes. The app is signed ad-hoc because there's no Apple developer account behind it. The first time, right-click the app and choose Open. On macOS 15 or later, go to System Settings → Privacy & Security and click Open Anyway.

Where does my data live?

The board, settings and secret live in ~/Library/Application Support/Agent Desk. Agent worktrees and screenshots go in .agent-desk/ inside each project, which is kept out of git.

How does it update?

The version pill next to the logo checks GitHub releases. When a newer one is out it says Update, and one click downloads the new .dmg to your Downloads folder.

Can I build it myself, or run it on an Intel Mac?

Yes, from source: clone the repo, then npm install and npm run app. npm start runs it in your browser instead, and npm run dist builds a .dmg for your Mac. It's open source under the MIT licence.
